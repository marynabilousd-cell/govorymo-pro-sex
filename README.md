# ГОВОРИМО ПРО СЕКС — лендінг клубу

Статичний односторінковий сайт (HTML + CSS + JS, без збірки). Готовий до публікації на GitHub Pages.

Структура сторінки побудована за AIDA:
увага (шапка з офером) → інтерес (проблематика) → бажання (наповнення клубу) →
довіра (фото + відгуки) → дія (тарифи й реєстрація) → задоволення (гарантія конфіденційності).

Тексти всіх блоків — у [landing-copy.md](landing-copy.md).

## Структура

```
landing/
├── index.html                  # головна сторінка (6 блоків за AIDA)
├── landing-copy.md             # структура та тексти лендінгу
├── 404.html                    # сторінка помилки
├── assets/
│   ├── css/style.css           # усі стилі + адаптив
│   ├── js/main.js              # меню, скрол-ефекти, валідація форми
│   └── img/
│       ├── favicon.svg
│       └── og-image.svg        # прев'ю для соцмереж
├── .nojekyll                   # вимикає обробку Jekyll на Pages
├── robots.txt
├── .gitignore
└── .github/workflows/deploy.yml  # автодеплой на Pages
```

## Локальний запуск

Достатньо відкрити `index.html` у браузері. Або підняти локальний сервер:

```bash
python -m http.server 8000
```

## Що потрібно заповнити перед публікацією

У [index.html](index.html) всі місця під заміну позначені коментарями `▼ ЗАМІНІТЬ ▼`:

1. **Рекламне відео** (блок 1) — розкоментувати `<iframe>` з YouTube або `<video>` з файлом
   і видалити `.video__placeholder`.
2. **Фотогалерея** (блок 4) — замінити 5 плейсхолдерів `.gallery__item` на `<img>` з реальними фото.
3. **Відгуки** (блок 4) — замінити на справжні, з письмовою згодою людей на публікацію.
4. **Ціни** (блок 5) — замість `ХХ ХХХ ₴` вписати реальну вартість членства та VIP-формату.
5. **Посилання лід-магніту** (блок «Лід-магніт») — `href="#"` → посилання на Telegram-бота / Viber.
6. **Контакти й документи** (підвал) — Instagram, Telegram, email, оферта, політика конфіденційності.
7. **`og:image`** — після деплою вказати абсолютний URL, соцмережі не бачать відносні шляхи.

Кольори та шрифти змінюються в блоці `:root` у [style.css](assets/css/style.css).

## Збір заявок

Форма зараз лише валідує дані на клієнті — GitHub Pages є статичним хостингом.
Для реального збору заявок підключіть зовнішній сервіс (Formspree, Google Forms, Telegram-бот
або власний API) у блоці «Форма заявки» в [main.js](assets/js/main.js).

## Публікація на GitHub Pages

1. Залийте код у репозиторій:

```bash
git add . && git commit -m "Лендінг клубу" && git push
```

2. У репозиторії відкрийте **Settings → Pages** і в полі **Source** оберіть **GitHub Actions**.
3. Після пушу в `main` воркфлоу задеплоїть сайт автоматично.

Сайт буде доступний за адресою `https://USERNAME.github.io/REPO/`.

> Альтернатива без Actions: у **Settings → Pages** обрати *Deploy from a branch* → `main` / `root`.
> Файл `.nojekyll` уже додано, тож нічого не зламається.

## Власний домен

Створіть файл `CNAME` у корені з доменом (одним рядком), напр. `club.example.com`,
і додайте DNS-запис у реєстратора.
